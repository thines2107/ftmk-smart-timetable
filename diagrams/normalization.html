Rule Applied: Each column must contain only one atomic value per row. Repeating groups are eliminated by expanding each subject into its own row. All cells now hold a single value.

2NF
Second Normal Form (2NF)
Rule Applied: Remove partial dependencies. The composite key for the 1NF table is (matric_no, subject_code, day, start_time). Attributes that depend only on part of this key are moved to separate tables.

Partial dependencies identified:
• student_name, course, year, group_name → depend only on matric_no → moved to users table
• subject_name → depends only on subject_code → captured in timetable table
• lec_email, lec_dept, lec_office → depend only on lecturer_name → moved to lecturer_profiles table

3NF
Third Normal Form (3NF)
Rule Applied: Remove transitive dependencies. No non-key attribute should depend on another non-key attribute.

Transitive dependency identified:
• In timetable: id → lecturer_name → lec_email, lec_dept, lec_office
   The contact details depend on lecturer_name, not the primary key. → moved to a separate lecturer_profiles table.
• Additionally, saved_timetables and saved_friends are introduced as separate entities with proper FK references.
